# ITGEL KINO (Итгэл Кино) - Монгол Киноны Вэб Сайт

Веб програмчлал, IT хичээлийн 8-р долоо хоногийн бие даалт. Монголын сор бүтээл болох **"Итгэл" (2016)** уран сайхны киног онцолсон, Монгол киноны орчин үеийн синематик цахим сан.

---

## 🌟 Гол боломжууд

1. **Онцлох киноны Hero Banner ("ИТГЭЛ" кино)**:
   - Киноны 4K танилцуулга, Азийн наадмын шилдэг шагналын мэдээлэл.
   - Шууд үзэх, Трейлер үзэх, Жагсаалтад нэмэх товчлуурууд.
2. **"Итгэл" киноны бие даасан тусгай хуудас (`itgel-movie.html`)**:
   - Дүрүүдийн дэлгэрэнгүй танилцуулга (Б.Амарсайхан, С.Болд-Эрдэнэ, Ц.Цэрэнболд, Б.Мишээл).
   - Оскарт нэр дэвшсэн болон Азийн кино наадмын шагналуудын жагсаалт.
   - Киноны алдарт ишлэлүүд болон суурилагдсан видео тоглуулагч.
3. **Монгол киноны баялаг сан (12 шилдэг кино)**:
   - Итгэл, Аав, Үргээлэг, Содура, Зүрхний хилэн, Баавгай болохсон, Байтаг богд, Шүүдэр дундуур, Буруу өрөг, Холливудад хүрэх зам, Монгол (Чингис хаан), Галзуу зугаалга.
4. **Хайлт ба Шүүлтүүр (Real-time Filter & Search)**:
   - Түлхүүр үг, жүжигчин, найруулагчийн нэрээр шууд хайх.
   - Төрөл жанраар шүүх (Драм, Түүхэн, Тулаант, Гэр бүл, Хайр дурлал, Инээдэм, Триллер, Эр зориг).
   - Эрэмбэлэх сонголт (Үнэлгээгээр, Шинээр нэмэгдсэнээр, Хуучин үеийн бүтээлүүдээр, Нэрээр).
5. **Интерактив Видео Тоглуулагч Модал (Video Player Modal)**:
   - HTML5 дээр суурилсан кино тоглуулагч.
   - Сервер солих сонголтууд (Сервер 1 - Үндсэн HD, Сервер 2 - VIP 4K, Сервер 3 - Трейлер).
6. **Дэлгэрэнгүй мэдээлэл ба Сэтгэгдлийн систем (Reviews & Ratings)**:
   - Хэрэглэгч өөрийн сэтгэгдэл, одны үнэлгээ өгөх боломжтой.
   - `localStorage`-д хадгалагдах тул хуудас дахин ачааллахад алга болохгүй.
7. **Миний жагсаалт (Watchlist Drawer)**:
   - Дуртай кинонуудаа хадгалах, хасах боломжтой.
8. **Кино санал болгох форм**:
   - Үзэгч хүссэн Монгол киногоо нэмүүлэхээр хүсэлт илгээх хэсэг.

## 📁 Файлын бүтэц

```text
web wek 8 kino side/
├── index.html            # Нүүр хуудас (Бүх киноны сан, хайлт, модал)
├── itgel-movie.html      # "Итгэл" киноны бие даасан тусгай хуудас
├── css/
│   └── style.css         # Dark cinematic дизайн, Responsive хэв маяг
├── js/
│   ├── movies-data.js    # Кинонуудын өгөгдлийн сан (JSON бүтэцтэй)
│   └── main.js           # Тоглуулагч, шүүлтүүр, сагс, хайлт, модал кодууд
├── assets/               # Вектор SVG постерууд, баннерууд, лого
├── generate-assets.js    # Постер, зураг үүсгэгч скрипт
└── README.md             # Төслийн заавар
```
